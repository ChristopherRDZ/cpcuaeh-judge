{#- The autocompletion of the code editors (2026-11-08), shared by the submit page, the custom test and the duel page. As one types, the editor suggests words already in the code (the names one declared), keywords of the language and, in C and C++, headers: «#incl» offers whole #include lines, and inside «#include <» the header names. Tab or a click takes a suggestion; Enter always makes a new line (the owner's choice, 2026-11-08). No block snippets. It needs the ext-language_tools.js of the same Ace, loaded after ace.js; without it nothing happens. Each page says whether it is allowed there; where it is, it starts on, and the person can turn it off with the box next to the language, remembered in their browser for every editor. Kept outside the compressed blocks on purpose: changing it does not touch the offline compression manifest. -#}
